## 改动落点

- `tests/e2e/redesign.spec.ts`：补充真实 Chromium 浏览器断言，验证笔记标题输入框在常态、悬停、点击聚焦与键盘聚焦下均无边框与聚焦底边线。
- `docs/tasks/290.md`、`docs/tasks/README.md`：登记本任务卡。

## 实施步骤

1. 在 `tests/e2e/redesign.spec.ts` 中新增笔记标题输入框无边框的真实 Chromium 断言，先复现 RED（聚焦态存在 `mtone` 绘制的 `box-shadow` 底边线且 `border-width` 为 `1px`）。

3. 运行 `pnpm install --frozen-lockfile`、`pnpm run typecheck`、`pnpm run lint`、`pnpm run test`、`pnpm run build`、`pnpm exec eslint tests/e2e playwright.config.ts` 以及真实 Chromium Playwright 回归测试并核验视觉结果。

## 验证场景与预期结果

- 打开笔记编辑页（`/notes` 与 `/notes/$noteId`），标题输入控件（`aria-label="笔记标题"`）在常态、悬停、点击聚焦及键盘 Tab 聚焦状态下，四边 `border-width` 均为 `0px`、`border-style` 为 `none`，`box-shadow` 为 `none`，常规浅色模式下无可见边框、底线或外轮廓。
- 编辑标题文本、触发自动保存、刷新及无障碍名称（`textbox` `"笔记标题"`）行为保持正常。
