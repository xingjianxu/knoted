# #292 笔记侧栏目录采用 mtone Tree 节点操作并补充悬停操作菜单

## 改动落点

- `apps/web/src/features/notes/NotesPage.tsx`：
  - 笔记目录树消费 `@bixlab/mtone` `Tree` 的 `showLine`、`titleRender` 与 `actions` 能力，为每个节点提供仅在悬停/聚焦时显示的右侧按钮（`visibility: "hover"`）：`+` 添加子页面按钮，以及 `...` 图标按钮配合 `Popover.Menu`（`triggerMode="hover"`）悬停弹出常用页面操作菜单。
  - 将移动（`Dialog` + `TreeSelect`）与删除（`ConfirmDialog`）对话框提升至 `NotesPage` 以支持目录树任意节点与当前页操作条共用，统一并发锁并新增重命名对话框、创建副本与复制链接功能；对当前编辑节点保持草稿、CAS 版本与编辑器实例不重载，对非当前节点同步清理旧会话缓存并刷新完整目录。
- `apps/web/src/features/notes/autosave.ts`：在 `NoteEditingSession` 新增原子 `renameTitle` 方法，先等待在途 `PATCH`/历史写入完成后再提交重命名，失败时不污染实时编辑器草稿。
- `apps/web/src/features/notes/queries.ts`：在 `noteTree` 中为空/全空白标题提供「未命名笔记」回退标签，确保目录树与移动选择器的无障碍名称和可见文本一致。
- `apps/web/tests/tasks/t31.test.tsx`：补充侧栏树节点 `+` 新建子页面、`...` 菜单重命名（当前/非当前节点）、创建副本、移动到、复制链接、删除与撤销恢复及失败路径的 Vitest 测试。
- `tests/e2e/redesign.spec.ts`：补充真实 Chromium Playwright 回归测试，验证未悬停隐藏、悬停显现、点击 `+` 添加子页面、悬停 `...` 弹出菜单并移入执行页面操作。
- `docs/tasks/292.md`、`docs/tasks/README.md`：登记本任务卡。

## 实施步骤

1. 在 `NotesPage.tsx` 梳理当前编辑节点与非当前节点的统一页面操作（新建子页面、重命名、创建副本、移动到…、复制链接、删除页面），复用 mtone `Tree.actions`、`Popover.Menu`（`triggerMode="hover"`）、`Dialog`、`ConfirmDialog` 与 `useToast`。
2. 在 `apps/web/tests/tasks/t31.test.tsx` 新增并运行 Vitest 用例，验证全部树节点操作的正常路径、失败路径、草稿保护与 CAS 一致性。
3. 在 `tests/e2e/redesign.spec.ts` 新增真实 Chromium 测试，验证 hover 可见性样式、悬停菜单交互与跨断点无溢出。
4. 运行 `pnpm install --frozen-lockfile`、`pnpm run typecheck`、`pnpm run lint`、`pnpm run test`、`pnpm run build`、`pnpm exec eslint tests/e2e playwright.config.ts` 及 Playwright 浏览器回归。

## 验证场景与预期结果

- 未悬停/未聚焦树节点时，节点右侧 `+` 与 `...` 按钮视觉隐藏（`opacity: 0`、`pointer-events: none`）；悬停节点时两个按钮显示。
- 点击节点右侧 `+` 按钮直接在该节点下创建子页面并展开父节点，且不破坏当前页面的未保存草稿保护。
- 悬停节点右侧 `...` 按钮弹出操作菜单，鼠标移入菜单保持打开，点击或键盘操作同样可用；可执行新建子页面、重命名、创建副本、移动到…、复制链接（显示成功提示）与删除页面（保留恢复回执及有子页阻止提示）。
- 既有笔记编辑、自动保存、历史恢复、版本冲突、导航拦截与安全退出测试全部通过，宽窄屏均无横向溢出。
