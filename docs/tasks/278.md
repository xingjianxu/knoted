# #278 调整项目 npm 源为官方源、升级 mtone 0.13.2 并用 Splitter 重构笔记页面

[GitHub Issue #278](https://github.com/xingjianxu/knoted/issues/278) · Feature

- 分支：`issue-278-notes-splitter`
- Worktree：`.worktrees/278-notes-splitter/`
- 相关文档：[UI 指南](../development/ui-mtone.md)、[ADR 0002](../decisions/0002-mtone-ui-ownership.md)
- 直接前置：无（`@bixlab/mtone@0.13.2` 已发布至 npm 官方源）

## 范围和步骤

1. 在仓库根目录新增 `.npmrc` 固定 `registry=https://registry.npmjs.org/`，使项目内 npm/pnpm 统一使用官方源。
2. 将 `apps/web/package.json`、`pnpm-workspace.yaml` 和 `pnpm-lock.yaml` 中的 `@bixlab/mtone` 精确升级至 `0.13.2`，核验无无关依赖漂移并同步更新 [UI 指南](../development/ui-mtone.md)。
3. 在 [认证外壳](../../apps/web/src/routes/_authenticated.tsx) 与 [样式入口](../../apps/web/src/styles.css) 为笔记路由提供铺满剩余高度的无内边距工作区容器，并在 [NotesPage](../../apps/web/src/features/notes/NotesPage.tsx) 使用 mtone `Splitter` / `Splitter.Panel` 重构左右分栏：
   - 左侧面板使用 mtone `Sidebar` 与 0.13.2 增强版 `Tree`（`directory`、`expandAction={false}`、`indent={14}`、`gap={2}`、`selectedKeys`/`expandedKeys`）展示文档树。
   - 右侧面板展示当前笔记内容，进入 `/notes` 且树非空时默认展示树根第一个笔记的内容，同时保留窄屏 `Drawer` 目录切换与编辑器实例/草稿/冲突/导航拦截保护。
   - 使用 mtone `Toolbar`、`Status`、`Input`（`variant="borderless"`）、`Divider`、`Tooltip`、`Form`、`Card`、`Tag`、`Popover.Menu` 等组件优化笔记主体、移动对话框、历史版本与标签关联面板。
4. 补充 Vitest 与真实 Chromium Playwright 验收测试，覆盖官方源配置、默认首篇笔记、Splitter 分栏与拖拽、窄屏抽屉及既有草稿/历史/冲突/退出场景。

## 验收

- 项目内 `pnpm config get registry` 与 `npm config get registry` 均返回 `https://registry.npmjs.org/`，`pnpm install --frozen-lockfile` 通过，`@bixlab/mtone` 精确锁定 `0.13.2`。
- 宽屏下笔记页面使用 `Splitter` 左右分栏，左侧面板为 `Sidebar` 文档树，右侧面板为笔记内容主区，分隔条可拖拽且在 1440px、768px、390px、320px 下均无横向溢出。
- 访问 `/notes` 且存在笔记时，默认展示树根第一个笔记的内容并高亮对应树节点；无笔记时展示空状态与新建入口；删除笔记后保留撤销恢复提示。
- `pnpm run typecheck`、`pnpm run lint`、`pnpm run test`、`pnpm run build` 及 Playwright 浏览器回归全部通过。
