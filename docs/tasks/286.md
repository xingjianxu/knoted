# #286 升级 @bixlab/mtone 至 0.15.2 并迁移编辑器至 @bixlab/mtone-blockeditor@0.2.0

[GitHub Issue #286](https://github.com/xingjianxu/knoted/issues/286) · Task

- 分支：`issue-286-mtone-blockeditor`
- Worktree：`.worktrees/286-mtone-blockeditor/`
- 相关设计/架构文档：[UI 指南](../development/ui-mtone.md)、[ADR 0002](../decisions/0002-mtone-ui-ownership.md)
- 直接前置：无（`@bixlab/mtone@0.15.2` 与 `@bixlab/mtone-blockeditor@0.2.0` 已发布至 npm 官方源）

## 交付目标

将前端 UI 依赖 `@bixlab/mtone` 精确升级至 `0.15.2`，安装并精确锁定 `@bixlab/mtone-blockeditor@0.2.0`，使用公开 `BlockEditor` 控件与 `@bixlab/mtone-blockeditor/styles.css` 替代 `apps/web` 中直接依赖与使用的 `@blocknote/core` / `@blocknote/react` 及手写编辑器工具栏、斜杠菜单、块操作菜单和块控件。同时保留 Knoted 后端 `NoteDocument` v1 持久化契约、图片 `/api/v1/assets` 上传与 `asset_id` 边界、自动保存/冲突恢复/历史只读预览与无障碍体验。

## 改动落点

- 依赖与配置：`apps/web/package.json`、`pnpm-workspace.yaml`、`pnpm-lock.yaml`（移除直接依赖 `@blocknote/core`、`@blocknote/react`）。
- 样式入口：`apps/web/src/styles.css`、`apps/web/src/features/notes/notes-workspace.css`。
- 笔记编辑器：`apps/web/src/features/notes/editor/`（重写 `note-editor.tsx`、`document-adapter.ts`、`index.ts`，新增 `image-upload.ts`，移除直接依赖 BlockNote 的 `schema.tsx`、`formatting-toolbar.tsx`、`menus/*`、`blocks/*`）。
- 笔记与历史页面：`apps/web/src/features/notes/NotesPage.tsx`、`apps/web/src/features/notes/HistoryPanel.tsx`。
- 测试与夹具：`apps/web/tests/tasks/{t02,t17,t27,t28,t29,t30,t31}.test.tsx`、`apps/web/tests/fixtures/{t27-editor,t28-editor,t29/main}.tsx`、`tests/e2e/redesign.spec.ts`。
- 文档：`docs/development/ui-mtone.md`、`docs/tasks/286.md`、`docs/tasks/README.md`。

## 实施步骤

1. 在独立 worktree `.worktrees/286-mtone-blockeditor/` 精确锁版 `@bixlab/mtone@0.15.2` 与 `@bixlab/mtone-blockeditor@0.2.0`，移除直接依赖 `@blocknote/core` / `@blocknote/react`，同步 `pnpm-workspace.yaml` 精确等待期例外与 `pnpm-lock.yaml`。
2. 在 `apps/web/src/styles.css` 导入 `@bixlab/mtone-blockeditor/styles.css`，调整 `notes-workspace.css` 适配 `.mt-block-editor`。
3. 基于 `@bixlab/mtone-blockeditor` 公开类型与 `BlockEditor` 重写 `document-adapter.ts`、`image-upload.ts` 与 `note-editor.tsx`，清理直接依赖 `@blocknote/*` 的旧编辑器源码并更新 `NotesPage` 与 `HistoryPanel`。
4. 迁移 Vitest 测试与浏览器夹具（零直接 `@blocknote/*` 导入），补充真实 Chromium Playwright 编辑器与布局回归测试。
5. 更新 `docs/development/ui-mtone.md`，运行全部本地检查、独立审查、PR 普通合并、主线复核与 `pnpm deploy:dev` 部署验证。
