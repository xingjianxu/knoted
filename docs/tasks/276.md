## 范围和步骤

1. 在 [认证路由外壳](../../apps/web/src/routes/_authenticated.tsx) 使用 `AdminLayout.Header` 的 `breadcrumb` 和 `extra` 插槽。左侧显示当前位置，项目、事项和文件详情保留清单返回链接。
2. 桌面显示全局搜索、通知和账号设置，头像菜单提供退出。以侧栏现有的 768px 断点切换顶栏，窄屏从「更多操作」访问同一组功能。搜索和设置接入已有路由，通知显示空状态，沿用笔记安全退出流程。
3. 更新 [浏览器布局回归](../../tests/e2e/admin-layout.spec.ts) 和已有退出场景，运行适用 Web 检查。

## 验收

- 1440、768、390、320 CSS px 下顶栏和侧栏品牌区底边对齐，当前模块、详情返回及对应的桌面或窄屏按钮可见。320px 手动展开侧栏后，详情返回和更多操作仍可点击。
- 搜索和设置能打开现有页面，键盘可打开窄屏菜单和通知，关闭通知后焦点回到触发入口。
- 窄屏退出跳转到登录页。有未保存笔记且保存失败时，退出受阻，草稿保留，可重试。
