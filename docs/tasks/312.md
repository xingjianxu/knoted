2. 在 [Chromium 布局回归](../../tests/e2e/redesign.spec.ts) 检查分栏外框与目录交互，运行 Web 本地门禁。

## 验证场景与预期结果

- 桌面和窄屏的笔记分栏整体均显示四边 1px 实线主题外框。
- 桌面可拖动分隔条调节目录宽度，窄屏可打开目录抽屉并切换笔记。
