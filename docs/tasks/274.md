## 范围和步骤

1. 在 `tests/e2e/admin-layout.spec.ts` 为已登录项目详情页补充 Chromium 几何回归，先用 0.13.0 复现。
2. 在 `apps/web/package.json`、`pnpm-workspace.yaml` 和 `pnpm-lock.yaml` 精确锁定正式 npm 版本 0.13.1。
3. 复测宽屏展开、窄屏自动收起和操作可见性，运行 Web 门禁及工作区布局回归。独立审查后合入、复核并回写 Issue。

## 验收

- 在 1440px 宽屏及 390px、320px 窄屏，项目详情页的返回项目、退出登录完整可见，两条底边的纵向坐标相同。旧版三个宽度均实测右侧底边低 1 CSS px。
- 已登录和未登录路由、折叠、键盘导航和主区滚动继续通过既有 Playwright 验收。
- 冻结安装通过，Web 门禁无失败，锁文件仅升级 mtone 到 0.13.1。
