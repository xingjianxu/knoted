## 实施步骤

1. 核对发布包的公开入口、样式入口和 React peer 范围。
2. 在 `apps/web/package.json` 精确锁定两个版本，更新 `pnpm-workspace.yaml` 的精确等待期例外，用 pnpm 生成 `pnpm-lock.yaml`，同步 T17 的精确版本断言和 UI 指南。
3. 运行适用的 [Web/API 本地门禁](../development/validation.md) 和 Chromium 回归。

## 验证场景与预期结果

- 冻结安装成功，两个直接依赖及 BlockEditor 使用的 mtone peer 均解析到目标版本。
- API 示例与生成契约检查、类型检查、lint、Web 单测、进程编排测试和生产构建通过。
- Chromium 中笔记分栏、同级拖动排序、编辑器斜杠菜单、图片上传、保存冲突和历史预览通过回归。
- 独立审查后合入主线，开发实例部署包含本次合并提交的版本并通过健康检查。
