# #272 升级并迁移前端至 @bixlab/mtone@0.13.0 并全面采用 mtone 组件

[GitHub Issue #272](https://github.com/xingjianxu/knoted/issues/272) · Task

- 分支：`issue-272-mtone-0-13`
- Worktree：`.worktrees/272-mtone-0-13/`
- 相关设计/架构文档：[UI 指南](../development/ui-mtone.md)、[ADR 0002](../decisions/0002-mtone-ui-ownership.md)
- 直接前置：无

## 交付目标

将 `apps/web` 的 UI 组件库依赖从 `@bixlab/mtone@0.8.0` 精确升级并迁移至 `@bixlab/mtone@0.13.0`，完成 0.8.0 → 0.13.0 全部破坏性变更适配，并系统性梳理全站前端页面，将可用 `@bixlab/mtone@0.13.0` 公开组件表达的原生表单分组、卡片面板、分隔线、工具栏、树形父笔记选择、代码/排版与适用页面结构迁移为 mtone 公开组件（保留路由集成、BlockNote 编辑器核心、业务语义与无障碍契约）。

## 范围与落点

- 依赖与配置：`apps/web/package.json`、`pnpm-workspace.yaml`、`pnpm-lock.yaml`。
- 文档与任务索引：`docs/development/ui-mtone.md`、`docs/tasks/272.md`、`docs/tasks/README.md`。
- 破坏性变更迁移（0.8.0 → 0.13.0）：
  - `Badge` → `Tag`
  - `FilterBar` → 布局容器 / `Toolbar`
  - `FormField` → `Form.Item`
  - `Textarea` → `Input.TextArea`
  - `SearchInput` → `Input.Search`
  - `MultiSelect` → `Select mode="multiple"`
  - `DropdownMenu` 与带 `trigger` 的 `Menu` → `Popover.Menu`
  - `Segmented` → `RadioGroup variant="segmented"`
  - 控件默认高度（34px → 32px）与普通单选 `Select` 宽度行为适配
- 全站 mtone 组件采用：`apps/web/src/routes/` 与 `apps/web/src/features/` 下的表单（`Form` / `Fieldset`）、卡片（`Card` / `CardGroup`）、分节与分隔（`SectionGroup` / `Divider`）、工具栏（`Toolbar`）、树形选择（`TreeSelect`）、排版与代码（`Typography` / `Link`）以及适用页面的高阶组件（按 0.13.0 实际公开类型与无障碍契约核验落地）。
- 测试与夹具：`apps/web/tests/fixtures/*`、`apps/web/tests/tasks/*`、`tests/e2e/*`。

## 实施步骤

1. 创建 `issue-272-mtone-0-13` 与 `.worktrees/272-mtone-0-13/`，登记本任务卡与索引。
2. 精确锁版 `@bixlab/mtone@0.13.0`，同步 `pnpm-workspace.yaml` 精确等待期例外并更新 `pnpm-lock.yaml`；核查安装后的 `llms.txt`、`dist/index.d.ts` 与 `dist/styles.css`。
3. 完成 0.8.0 → 0.13.0 全部破坏性 API 迁移，修复类型、样式与消费测试。
4. 逐页迁移可由 mtone 0.13.0 公开组件替代的原生 HTML 与手写容器/工具栏/分组/选择器，验证布局、交互、键盘焦点与无障碍属性。
5. 更新 `docs/development/ui-mtone.md` 升级记录，运行本地前端门禁与真实 Chromium E2E，完成独立审查、PR 合并、主线复核、Issue 回写与工作区清理。
