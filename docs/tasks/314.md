1. 确认旧实例升级和备份恢复的兼容方案，更新架构记录。
2. 让 Rust 搜索仅处理笔记、项目和事项，移除文件正文索引、RAG、问答、后台提取及公开任务接口，处理旧任务、备份和恢复。

## 验证场景与预期结果

- 扫描或更新文件后，Worker 不会创建或重试已下线的全文索引、分块和向量任务。既有数据和任务历史仍可保存在数据库和备份中。
- 自动发现的文件可浏览、下载和预览。问答、文件任务与手动扫描入口已下线。
- 全站搜索支持笔记、项目和事项，历史文件或问答索引数据不会出现在结果里。
- 更新和隔离恢复保留业务及认证数据，常规运行只需要 API、Worker 及保留功能的依赖。
- 本地和远端归档分支均指向改动前提交。
