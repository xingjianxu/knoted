## 改动落点与实施步骤

1. 按维护者确认记录全新数据库、开发和生产数据清理及备份格式。
2. 让 Rust 搜索仅处理笔记、项目和事项，移除文件正文索引、RAG、问答、后台提取及公开任务接口，提供全新迁移和当前版本的备份与隔离恢复。
3. 更新 Web 路由和菜单、OpenAPI、生成客户端与测试夹具，移除 Python intelligence 服务及模型部署依赖。
4. 在隔离实例核对全新安装与备份恢复，执行本地检查、独立审查和 PR 集成。
5. 清空开发和生产的 Knoted 应用数据及专属数据库、附件备份，部署并核对版本与健康。

## 验证场景与预期结果

- 扫描或更新文件后，Worker 不会创建或重试已下线的全文索引、分块和向量任务。新库仅包含保留功能的表。
- 自动发现的文件可浏览、下载和预览。问答、文件任务与手动扫描入口已下线。
- 全站搜索支持笔记、项目和事项，历史文件或问答索引数据不会出现在结果里。
- 当前版本的归档可恢复业务及认证数据，常规运行只需要 API、Worker 及保留功能的依赖。
- 本地和远端归档分支均指向改动前提交。
