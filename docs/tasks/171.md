- 遇到继承属性名形式的后缀时，提示格式不支持预览，无原件内容请求和 Blob URL 创建。普通下载仍由弹层提供。
- PNG、JPEG 和 WebP 继续按后缀、MIME 和字节结构校验，并按既有方式预览。
