## 实施步骤

1. 在宿主配置中为开发实例定义专用 Meilisearch 单元，固定支持中文分词的官方构建，绑定回环端口 `15605`。开发 API 和 Worker 继续由 pcwrap 管理。
2. 在隔离搜索实例验收候选构建。开发搜索停止写入后，将现有数据复制到持久服务目录，核对复制结果，再由专用单元接管。保留原数据用于回退。
3. 启用专用单元并运行开发部署。记录宿主配置提交、实际服务版本以及应用部署版本。

## 验收场景

- 专用单元受启动目标管理，重启该单元后健康检查返回 200，既有开发索引统计保持一致。
- 隔离搜索实例能在中文句子中匹配关键词。Knoted 开发部署成功后，搜索配置仍启用并指向回环服务。
