## 实施步骤

1. 精确升级 `@bixlab/mtone` 至最新正式版 `1.2.0`（确认 `@bixlab/mtone-blockeditor@1.1.0` 已为最新版且 peer 依赖兼容），同步更新 `pnpm-workspace.yaml` 等待期例外与 `pnpm-lock.yaml`，核对无无关依赖漂移。
2. 将全站已登录外壳 `_authenticated` 从 `AdminLayout` 迁移至 `AppLayout`（`fullHeight`、`sidebarWidth={228}`、`sidebarCollapsible`、`contentAs="div"` 包裹单一 `<main>` 滚动容器），移除全站顶栏并将账号菜单（凭据与会话、通知、退出登录）集成至左侧栏左下角 `account` 插槽；仅在项目/事项/文件详情子路由保留返回面包屑 `Topbar`。
3. 将 `NotesPage` 从内嵌 `AppLayout` 重构为 mtone `1.2.0` 两栏 `PageLayout`（`bordered`、`headerSpan="main"`、`sidebarPosition="left"`、`sidebarResize` 单线分隔条），左侧栏为笔记目录树 `Sidebar`，右侧栏通过 `PageLayout` 的 `topbar` API 在顶部展示单行 `Topbar`（左侧为当前笔记路径面包屑与自动保存状态，无用户相关按钮；右侧为保存笔记图标按钮及标签、历史、更多操作图标按钮），并开启 `BlockEditor` `borderless` 实现无缝白纸编辑画布；窄容器 `< 40rem`（640px）统一由 `data-notes-narrow` 驱动省略内联侧栏并由顶栏目录图标按钮打开 `Drawer`。
4. 同步将回收站、文件列表纳入 `PageLayout` / `Card` 统一边框视觉，更新 Vitest 与 Chromium Playwright 端到端回归测试，执行全部本地必需门禁。

## 验证场景与预期结果

- `pnpm install --frozen-lockfile` 通过，`@bixlab/mtone` 精确锁定 `1.2.0`，`@bixlab/mtone-blockeditor` 精确锁定 `1.1.0`。
- 全站所有已登录页面采用 `AppLayout`，无全局顶栏，左下角账户入口可打开 `凭据与会话`、`通知` 与 `退出登录`，侧栏可收起为 52px 图标窄栏并支持键盘访问；详情子路由在各宽度下保留返回顶栏。
- 桌面宽屏（1440px / 1280px）笔记页采用两栏 `PageLayout`：左侧为可拖拽调宽的笔记目录树侧栏，右侧上部通过 `PageLayout.topbar` 显示单行 48px `Topbar`（底边与侧栏标题行对齐、左侧路径面包屑、右侧保存图标按钮且无用户按钮），下部为居中限宽的无边框编辑画布。
- 窄屏（390px / 320px）隐藏内联笔记目录侧栏并由顶栏目录按钮打开抽屉，状态栏自动收缩为状态圆点避免文字截断，切换笔记与切换回宽屏时焦点正确恢复，所有页面均无横向溢出。
- `pnpm run typecheck`、`pnpm run lint`、`pnpm run test`、`pnpm test:pc`、`pnpm run build` 与全部 121 项 Chromium Playwright 测试全部通过。
