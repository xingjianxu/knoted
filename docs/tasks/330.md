## 实施步骤

1. 精确升级 `@bixlab/mtone` 至 `1.2.1`（`@bixlab/mtone-blockeditor@1.1.0` 保持不变），同步更新 `pnpm-workspace.yaml` 等待期例外与 `pnpm-lock.yaml`，核对无无关依赖漂移。
2. 对照 `mtone@1.2.1` `PageLayout` / `SidebarResizeOptions` 公开 API 更新 `NotesPage` 的 `PageLayout`，显式启用 `sidebarResize.separatorBordered` 并保留默认 Splitter 样式（分隔条两侧各 1px 实线边框，非单线 `line` 模式）；复核全站其余 `PageLayout` 页面兼容。
3. 将笔记页右上角「历史版本」迁入右侧 `Drawer`（`placement="right"`），与「标签与关联」右侧 `Drawer` 保持一致；移除原内联编辑区隐藏与重复标题/关闭栏，`HistoryPanel` 保留版本列表、只读预览、返回列表同步焦点恢复与恢复确认流程；窄屏笔记目录抽屉使用 `placement="left"` 从左侧弹出。
4. 在 `NoteAssociations` 中改用 mtone `Select`（`mode="tags"`）实现标签展示、搜索选择已有标签、输入新标签名创建并关联及移除标签，保留 401 失效后已创建标签 ID 的显式重试与资料关联功能。
5. 更新并补充 Vitest 单测与 Playwright Chromium 端到端测试，运行全部本地必需门禁。

## 验证场景与预期结果

- `pnpm install --frozen-lockfile` 通过，`@bixlab/mtone` 精确锁定 `1.2.1`，`@bixlab/mtone-blockeditor` 精确锁定 `1.1.0`，无无关依赖漂移。
- 桌面宽屏（1440px）笔记页两栏 `PageLayout` 的分隔条使用默认 Splitter 样式（`mt-splitter-separator-bordered`，不含 `mt-splitter-separator-line`），左右两侧各渲染 1px 实线边框且支持拖拽调宽。
- 笔记页右上角「标签与关联」与「历史版本」点击后均从右侧以 `Drawer` 弹出（`data-placement="right"`），关闭后焦点回到对应触发按钮且编辑器草稿与实例不重建；窄屏笔记目录抽屉从左侧弹出（`data-placement="left"`）。
- 标签抽屉通过 `Select` `tags` 模式支持选择已有标签（不重复 `POST /tags`）、输入并创建新标签（`POST /tags` + `PUT`）、点击芯片移除标签（`DELETE`），并在加载禁用、请求报错及 401 失效重登重试场景保持状态一致。
- `pnpm run typecheck`、`pnpm run lint`、`pnpm exec eslint tests/e2e playwright.config.ts`、`pnpm run test`、`pnpm test:pc`、`pnpm run build` 与全部 122 项 Chromium Playwright 测试全部通过。
