## 实施步骤

1. 核对发布包依赖、公开组件类型和样式入口。
2. 在 `apps/web/package.json` 精确锁定两个目标版本，更新 `pnpm-workspace.yaml` 对应的等待期例外，并用 pnpm 更新锁文件。
3. 在 `apps/web/tests/tasks/` 和 `tests/e2e/redesign.spec.ts` 对齐新版斜杠菜单入口、图注提示和图片上传确认流程，复核既有编辑与保存行为。
4. 更新 UI 指南和任务索引，运行适用的 [Web/API 门禁](../development/validation.md) 及 Chromium 回归。

## 验证场景与预期结果

- 冻结安装成功，两个直接依赖及编辑器使用的 mtone peer 均解析到目标版本。
- API 示例和生成契约、类型检查、lint、单元测试、进程编排测试及生产构建通过。
- 浏览器验证笔记侧栏、斜杠菜单、图片上传、非法块反馈、保存冲突和历史只读预览。
- 独立评审通过，合入主线并部署开发实例。
