## 改动落点

- 依赖与锁文件：`apps/web/package.json`、`pnpm-workspace.yaml`、`pnpm-lock.yaml`
- 笔记页面布局与样式：`apps/web/src/features/notes/NotesPage.tsx`、`apps/web/src/features/notes/notes-workspace.css`、`apps/web/src/features/notes/links/NoteAssociations.tsx`
- 测试与文档：`apps/web/tests/tasks/t17.test.tsx`、`apps/web/tests/tasks/t31.test.tsx`、`tests/e2e/redesign.spec.ts`、`docs/development/ui-mtone.md`、`docs/tasks/326.md`、`docs/tasks/README.md`

## 实施步骤

1. 将前端依赖 `@bixlab/mtone` 精确升级至 `1.0.0`、`@bixlab/mtone-blockeditor` 精确升级至 `1.1.0`，同步更新 `pnpm-workspace.yaml` 等待期例外、`pnpm-lock.yaml` 与 [UI 指南](../development/ui-mtone.md)，核对无无关依赖漂移。
2. 将 `NotesPage` 主体区域由 `Splitter` 替换为 `AppLayout`（`contentAs="div"`、`sidebarWidth={260}`、`sidebarResize={{ defaultWidth: 260, minWidth: 180, maxWidth: 420, separatorBordered: true }}`、`navigationLabel="笔记目录"`），左侧承载原有笔记目录树与新建根笔记入口，右侧内容区由上部 `Topbar`（`as="div"`）与下部独立滚动笔记内容区组成。
3. 在 `Topbar` 合理排布各项内容：左侧放置窄屏目录抽屉入口、当前笔记层级面包屑（支持点击父节点导航）与自动保存状态/基础版本号；右侧 `extra` 按操作层级排列冲突处理（按需出现）、标签与关联、历史版本、保存并记录历史主按钮与更多笔记操作菜单；窄容器下通过容器查询自动收起按钮文案为图标按钮并保留完整无障碍名称与标题提示。
4. 更新并补充 Vitest 与 Chromium Playwright 回归测试（含 `AppLayout` + `Topbar` 对齐与面包屑导航、窄屏焦点恢复与 `BlockEditor 1.1.0` 上下文表格操作菜单），执行本地必需门禁。

## 验证场景与预期结果

- `pnpm install --frozen-lockfile` 通过，`@bixlab/mtone` 精确锁定 `1.0.0`、`@bixlab/mtone-blockeditor` 精确锁定 `1.1.0`。
- 桌面宽屏（1440px / 1280px）左侧显示可拖拽调宽的笔记目录树侧栏，右侧上部显示单行 48px `Topbar`（底边与侧栏标题行对齐）、下部为居中限宽的可滚动笔记编辑/历史区；子笔记在 `Topbar` 面包屑展示父级路径并可点击跳转。
- 窄屏（768px / 390px / 320px）隐藏内联侧栏并由 `Topbar` 左侧按钮打开目录抽屉，切换笔记与切换回宽屏时焦点正确回到可见控件，长笔记滚动时 `Topbar` 保持可见，所有视口下无横向溢出。
- `BlockEditor 1.1.0` 斜杠菜单、图片上传与表格上下文菜单（`行操作` -> `向下添加行`）及所有 Vitest / Playwright / 构建检查全部通过。
