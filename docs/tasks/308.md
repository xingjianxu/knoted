# #308 修复笔记表格无法保存

[GitHub Issue #308](https://github.com/xingjianxu/knoted/issues/308) · Bug

- 分支 `issue-308-note-table-save`
- Worktree `.worktrees/308-note-table-save/`
- 相关文档 [表格保存 RFC](../rfcs/2026-11-26-note-table-persistence.md)、[ADR 0012](../decisions/0012-mtone-blockeditor-adoption.md)
- 直接前置为项目维护者确认笔记存储和 API 契约扩展方案。

## 实施步骤

1. 在独立 Chromium 夹具通过斜杠菜单插入表格并输入中文，以及粘贴 HTML 表格。两种方式均确认编辑器显示表格及告警，保存 JSON 没有表格或该文字。
2. 确认方案后，在 `crates/knoted-core/src/notes/document.rs` 实现表格校验和纯文本提取，在 `api/openapi.yaml` 更新文档类型并生成客户端。
3. 在 `apps/web/src/features/notes/editor/` 增加表格双向转换和相应失败提示。复用笔记的保存、历史和搜索链路。
4. 补齐 Rust、Web 与 Chromium 回归，并在独立实例验收。

## 验证场景与预期结果

- 插入和粘贴普通表格后可自动或手动保存。刷新、历史预览与恢复保留表格结构和受支持的单元格内容。
- 既有笔记与历史可继续打开和保存。搜索可命中表格文字。
- 不支持的结构、非法链接和超出限制的文档得到具体提示。失败时保留已保存版本。
