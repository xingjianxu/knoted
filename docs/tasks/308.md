- 跨模块契约已获维护者确认。直接前置无。

## 实施步骤

1. 在独立 Chromium 夹具通过斜杠菜单插入表格并输入中文，以及粘贴 HTML 表格。两种方式均确认编辑器显示表格及告警，保存 JSON 没有表格或该文字。
2. 先在 T22 增加表格顺序提取与边界用例。在 `crates/knoted-core/src/notes/document.rs` 接受 `table.rows[].cells` 及可选的 `header_rows`、`header_columns` 和 `column_widths`，各单元格复用 `InlineNode[]`。将已验证的表格投影到同一个块 ID。
3. 在 `api/openapi.yaml` 定义同一数据结构并生成客户端。用 T25 的真实 HTTP 和数据库夹具验证保存、冲突及历史恢复，用 T54 和 T57 验证全文及 RAG 检索。
4. 先在 Chromium 加入保存并刷新重开的失败用例。在 `apps/web/src/features/notes/editor/` 双向转换表格并验证输入，去除非链接告警中的链接建议。复用笔记的保存和历史链路。
5. 运行 Rust、Web、契约与 Chromium 检查，独立审查并按仓库流程完成开发实例部署。

## 验证场景与预期结果

- 插入和粘贴普通表格后可自动或手动保存。刷新、历史预览与恢复保留表格结构和受支持的单元格内容。
- 既有笔记与历史可继续打开和保存。搜索可命中表格文字。
- 不支持的结构、非法链接和超出限制的文档得到具体提示。失败时保留已保存版本。
