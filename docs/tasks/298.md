# #298 升级 mtone 并用 Container 布局笔记编辑区

- Issue：[xingjianxu/knoted#298](https://github.com/xingjianxu/knoted/issues/298)
- Type：Feature
- 直接前置：无
- 分支：`issue-298-note-editor-container`
- Worktree：`.worktrees/298-note-editor-container/`
- 关联：[UI 指南](../development/ui-mtone.md)、[BlockEditor 接入决策](../decisions/0012-mtone-blockeditor-adoption.md)、[正文区布局](296.md)

## 实施

1. 在 Web 依赖清单、工作区配置与锁文件精确锁定 npm 发布的 mtone `0.15.4`，核对最新的 BlockEditor `0.2.1` 及其 peer 依赖。
2. 在 `NotesPage.tsx` 直接消费 mtone 的 Container，以组件默认的 960 px 最大宽度和每侧 16 px 留白统一承载标题、分隔线和编辑器。由 `notes-workspace.css` 管理正文纵向排布，目录与操作栏位于 Container 外。
3. 在 `tests/e2e/redesign.spec.ts` 验证宽屏、分栏调整与窄屏，并运行前端本地检查。

## 验收

- 宽屏正文在右侧面板内居中限宽，空间不足时随面板缩小。标题和编辑器在同一 Container 内。
- 短笔记的可编辑区域填满分隔线下方的空间。长笔记末段可通过滚动到达，工具栏保持可见。
- 历史版本可打开、阅读和返回，当前笔记标题及正文仍可编辑。窄屏可单独打开目录。
