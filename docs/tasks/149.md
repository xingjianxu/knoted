## 实施与验收

1. 在 `crates/knoted-core/tests/t45.rs` 使用第三个 PostgreSQL 会话持有当前测试 schema 的关系锁。观察首个事务进入等待队列后启动第二个，两个事务均已排队时释放锁。
2. 分别固定标签分配、移除与重关联的两种顺序。标签先写使旧来源的版本比较失败，重关联先行时保留转移后的标签；核对双方备注及目标原有标签。
3. 对创建、删除关联各执行两种顺序，核对端点、版本和目标已有的关联。重关联先行时，使用旧关联版本的删除必须报告当前版本。
4. 在独立测试库执行 T45；每次锁等待及事务完成均有期限。
