# 子任务委派契约

为每次委派填完下表；纯研究或审查也要明确“只读”。平台适配见 [适配指南](agent-adapters.md)。

| 字段 | 必填内容 |
|---|---|
| 目标 / 验收 | 单一、可独立验证的结果 |
| 背景 / 输入 | GitHub Issue 编号、对应 `docs/tasks/<编号>.md`、相关代码、接口和已知问题 |
| 规则 / ADR | 适用 `AGENTS.md`、Skills 和相关 ADR 编号 |
| 修改范围 | 允许的文件/模块；只读则明确无写权限 |
| 分支 / Worktree | 主 Agent 已核验的独立分支及主仓库 `.worktrees/<编号>-<slug>` 或 `.worktrees/agent-<name>-<编号>` 绝对路径 |
| 输出 | 代码、文档或审查/研究结论；预期接口和格式 |
| 测试 | 命令、通过条件；无法执行时的报告要求 |
| 依赖 / 并行 | 上游成果、下游消费者、冲突文件负责人 |
| 禁止操作 | 主线写入、其他工作区写入、范围扩张、全局环境修改、危险清理 |
| 远程权限 | 默认继承 `AGENTS.md` 的远程操作授权；仅当用户限制时精确写仓库、对象、动作；不得转授更大权限 |

返回格式：完成情况；修改文件；实现说明；Commit ID（无提交写“无”）；测试命令与实际结果；未解决问题；风险；冲突。附工作区路径和当前 Git 状态，不只提供“全部完成”。

主 Agent 独立阅读差异、核对 commit 与分支来源、复跑必要验证后再集成。多个写 Agent 各有独立 Worktree，不通过共享工作区轮流暂存掩盖隔离问题；共享文件或强耦合接口串行执行。子 Agent 不合并主线、不删除其他 Agent 工作区。

没有 Subagent 能力时，主 Agent 按相同输入/输出与验收边界串行执行，并如实报告缺少独立审查的限制。
