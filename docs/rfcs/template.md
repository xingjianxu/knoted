# RFC: 方案标题

- Date: YYYY-MM-DD
- Status: Draft
- Owner: 负责人
- Related issues / ADRs: 真实链接；没有则写无
- Decision record: 尚未决定；Resolved 时链接 ADR 或未采纳原因

## 问题、目标与非目标

描述已有行为、用户影响、约束、成功标准及不解决的问题。

## 现状和备选方案

对比保留现状与候选方向，给出接口影响、成本、复杂度、证据和未知项。

## 推荐方案

说明推荐理由和依赖的假设，不把推荐写成已经批准。

## 影响与迁移

覆盖兼容性、数据、安全、权限、性能、运维、迁移阶段和回退；不适用项写明原因。

## 验证与开放问题

列出试验、测试、验收标准、需要谁确认的决定。未授权前只做非破坏性研究。

## 评审记录

记录参与者、日期、反馈和结论；最终决策单独形成 ADR。
