## 问题与目标

现有迁移前备份由运维停 API 和 Worker 后执行 `pg_dump` 并复制图片。T68 要保留可读服务，同时阻止新写入和任务领取，确认运行中的工作已退出，再在同一个数据库快照窗口保存数据库、所需图片和版本证据。T69 要验证内容后恢复至新建隔离目标，并撤销旧认证状态、重建派生索引。

数据库和注册图片是备份内容。只读源目录、模型、运行密钥、可重建索引、暂存文件和现场执行账本由各自的运行管理流程处理。隔离恢复完成后由操作者另行决定是否切换实例。

## 备选方案

| 方案 | 权衡 |
|---|---|
| 沿用停服务后备份 | 路径已做过 dev 验收。读请求在停机期间无法服务，退出确认和快照校验仍由操作者完成。 |
| 用数据库锁协调 API、Worker 和命令 | 既有 PostgreSQL 提供进程级互斥，连接断开释放锁。需要逐一接入写入口和 Worker 维护循环，明确在途工作和外部执行的退出条件。 |
| 仅由 PostgreSQL 导出快照 | 对 SQL 数据可获得一致视图。资产登记和对应文件的回收仍需跨资源互斥，数据库视图本身无法约束文件删除。 |

## 推荐方案

1. 使用实例数据库内共享与独占事务级 advisory lock。写操作和 Worker 每次任务或维护批次在开始前尝试共享锁，持有到本次工作及独立异步资产写入结束。备份有界等待独占锁。锁等待期间新写入返回维护错误，Worker 暂停领取和发布，已准入操作运行至结束。普通鉴权读取使用无续期读取路径。迁移与外部数据库写入安排在维护窗口之外。
2. 独占后核对 Job 租约、Python 持久退出证明、聊天上游停止证明和 Meilisearch 发布状态。Meilisearch 请求可能已被接收而任务号尚未入库，需核对受影响索引的待处理任务。拿不到可靠证明、锁连接失联或等待超时，都以未完成结束。
3. 取得独占锁并确认在途操作结束后，用另一连接开启 `REPEATABLE READ READ ONLY` 事务并导出快照。该事务读取资产登记与迁移版本，`pg_dump --format=custom --snapshot` 使用同一快照。独占连接持续保护图片复制，快照连接持续到导出完成。清单包括所有 `ready` 资产，含上传后尚未建立引用的图片。确认当前、历史及回收站引用对应可读资产，并校验文件摘要与数据库一致。备份目录私有，清单含格式版本、应用版本、迁移状态和各文件长度及 SHA-256。仅完整写入并核对后才发布完成清单，失败目录留作诊断。
4. 恢复先验证可信本地备份的清单及所有摘要，然后使用新数据库与新资产根。命令拒绝已存在的数据库、资产根和运行实例路径。目标使用独立的暂存目录及 Python 执行账本，启动前撤销旧会话、挑战及一次性授权。保留 Passkey 凭据、RP ID、业务版本、资产引用、聊天快照和历史，为隔离目标配置此 RP ID 下专用的 HTTPS origin。已有采集回执可能引用未归档的暂存输入。恢复时冻结相关旧作业，从获授权的只读源重新校验和采集，随后重建独立索引。失败目标继续隔离，保留诊断。
5. 备份前核对 API、Worker 和管理命令均支持同一锁键。使用现行的停止本实例写入后备份流程完成首次版本切换，保留 ADR 0007 的原实例升级回退流程和 SQLite 退出凭证。

## 影响与迁移

维护准入按读写行为划分。会话续期与 `GET /auth/session` 的 CSRF 轮换分支可能写入。聊天 `POST /events` 可以在使用无续期鉴权时继续回放。图片上传在请求断开后仍需持锁。Worker 的扫描与向量调度、聊天终态补偿、索引投递、历史维护和回收各自需要纳入准入，图片回收需覆盖数据库退役与文件删除的整个过程。管理命令发放凭据也使用同一准入。接入文件与验证范围见 T68 计划。

锁连接与业务连接需分配独立预算，避免小连接池互相等待。备份失败将由事务或连接结束释放独占锁。隔离目标保留诊断，后续重试选择新的空目标。数据库认证、测试实例编排和应用路径管理沿用既有 ADR。

恢复演练使用独立的 Meilisearch 实例和目标凭据。恢复的发布与清理任务可能携带源索引名，发布记录也可能携带源实例的任务号。启动恢复 Worker 之前隔离这些运行记录，按当前有效来源在目标实例重新投递文档全文、RAG 词法分块与向量，保留引用依赖使用的历史 chunk 和版本标识。备份摘要提供完整性校验，备份来源由操作者选择可信的本地产物。

## 验证与开放问题

- 本机 PostgreSQL 18.6 在隔离测试库的三连接探针中，独占锁排队时新的共享申请返回 `false`，独占退出后共享申请恢复为 `true`。该探针只证明本机锁行为。
- T68 应用测试覆盖有在途写入的维护准入，验证独占等待期间提交的业务数据及其图片一同进入备份，并覆盖失联、脱离 HTTP 请求的资产写入、外部任务接收结果不明、图片缺失、独占超时以及失败时恢复写入。
- T69 在新目标实测摘要错误拒绝激活、旧授权失效、现有 Passkey 重登、历史和引用保留及全文与向量重建。恢复夹具携带源索引名和已有任务号，验证源实例索引和任务状态完整保留。
- 规则 12 要求用户确认跨进程维护契约、备份包含的持久数据和恢复目标的隔离边界。T70 的生产接入另行确认。
- PostgreSQL 的快照时点和共享方法。 [事务隔离](https://www.postgresql.org/docs/18/transaction-iso.html#XACT-REPEATABLE-READ)、[快照同步](https://www.postgresql.org/docs/18/functions-admin.html#FUNCTIONS-SNAPSHOT-SYNCHRONIZATION)和 [pg_dump](https://www.postgresql.org/docs/18/app-pgdump.html#APP-PGDUMP-OPTIONS)。
