# T71 功能与故障集成验收

依据 [T71](knoted-v1/tasks/T71.md)、[验收矩阵](knoted-v1/acceptance.md) 与 T67–T70 证据。受控的浏览器夹具和独立实例可以提前准备。T71 最终验收读取 T70 的主机交接、验收产物和授权状态。

### Task 1: 独立浏览器场景

- [x] 使用独立 PostgreSQL、Meilisearch、Python 和 HTTPS 测试实例。固定合成源文件与应用版本，验证浏览器 Passkey 登录。使用实际 BGE-M3，模型回答使用受控本机夹具。
- [x] 通过扫描捕获、检索和问答消费真实文件来源。在浏览器确认引用有效，将回答保存为笔记，关联事项并刷新复验关系。
- [x] 让一个已索引文件在外部改变，控制索引发布。证明引擎仍保留旧结果时 API 已屏蔽旧版本，恢复发布后仅新版可见。
- [x] 运行 `pnpm exec playwright test tests/e2e/t71.spec.ts`。记录失败、跳过及环境限制，区分虚拟 Passkey 与硬件设备。

### Task 2: 汇总矩阵和依赖证据

- [x] 检查 [验收矩阵](knoted-v1/acceptance.md) 每行对应的测试、版本和真实运行输出。映射高风险缺口，保存退出码和用例数。另验证恢复缺图与全文可见同时向量任务失败。
- [x] 用当前固定产物复验 mtone 发布版的键盘、焦点、Portal、字体、中文输入法与选区。记录实际验证的边界。
- [ ] 验证 T70 的固定实例与主机证据。T70 通过后关闭 T71，向 T72 提供待核对事项。
