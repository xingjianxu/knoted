# 实施计划

复杂任务使用 Superpowers writing-plans，保存为 `YYYY-MM-DD-short-title.md`；用户指定的本目录优先于 Skill 默认路径。采用 [template.md](template.md)，已有计划优先增量更新。

计划必须能让新的 Agent 接手：目标、范围、依据、依赖、执行者、输入输出、Worktree、并行边界、验收、风险、测试、集成和清理均有记录。只有验证过的项才勾选；原生 TODO 不可用时，本文件检查清单兼任当前进度账本。
