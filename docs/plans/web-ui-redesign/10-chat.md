# 10 问答会话、引用与存为笔记

实施 Issue [#260](https://github.com/xingjianxu/knoted/issues/260) · [验收与限制](evidence/03-12.md)

目标是让使用者在长对话中继续提问、看清生成状态、核验引用并保存完整回答。依赖 01-foundation 已验收并锁定的最新正式版 mtone（仓库基线 0.6.0）。与 09-search 共用「搜索结果定位消息」验收场景。所有页面继续使用 AdminLayout.Content 作为工作区的滚动容器。

## 页面审计与排布

| 页面或交互面 | 当前表现 | 目标排布 |
| --- | --- | --- |
| `/chat` | 左侧会话列表与「新建会话」，右侧显示「请选择会话」或「暂无会话」。列表初次请求期间也可能出现「暂无会话」。 | 桌面显示会话索引与选择提示。窄屏以会话索引为主，首行标题和「新建会话」，列表可继续加载。只在成功且无数据时显示空态。 |
| `/chat/$chatSessionId` | 桌面有列表和会话两栏，窄屏整个列表排在消息前。每条消息均有卡片边框，大段问答阅读中角色和状态容易混在一起。 | 桌面紧凑会话栏 + 较宽正文。正文头是会话名和生成服务，用户问题用低对比底面，助手回答用连续正文，文字标明角色。手机按路由显示会话或消息，详情首行提供「返回会话列表」。 |
| 消息定位 `?message=<UUID>` | 在历史消息上设置焦点并滚入视口，找不到时显示提醒。 | 使用同一消息节点承载聚焦和视觉定位；给目标消息可见边界。长历史打开后保持目标处于可视区。 |
| 新建会话、引用、存为笔记 | 新建需选择本地或指定外部服务。每条完整回答有引用展开按钮和存为笔记弹层。 | 新建仍用 Dialog。引用在所属回答下就地展开，位置、片段、来源状态同组。存为笔记为次级动作，成功后就地改为「打开笔记」。 |

```text
问答         新建会话    │ 会话名                 本地／外部服务
当前会话                │ 你    问题
其他会话                │ 助手  正文、运行状态和可用动作
…                      │       查看引用    存为笔记
更多会话                │ [问题输入区                     ]
                        │ [资料范围 ▾]     外部发送提示  发送问题
```

列表用 List/ListItem 与实际 Link，当前项 aria-current。正文保留有序消息列表；减少重复边框，通过行距、角色文字和对齐区分问与答。问题输入区放在消息流末端，随工作区滚动，给引用展开、定位消息及手机软键盘保留空间。在问题框下用 Button 展开资料范围（类型 Checkbox + 项目／标签 MultiSelect），折叠时显示所选范围的简短摘要。对外发送提示始终紧邻提交按钮。窄屏按钮换行，打开筛选、引用和弹层均保持当前会话，仅切换路由才更换会话实例。

## 状态与交互边界

- **会话与提交。** 列表、详情、资料选项分别处理读取、空、失败与重试。新建保留可选名称、默认本地、具名外部服务校验。问题须非空，服务已接受后才清空原草稿；失败可再次显式发送。保留同一意图丢响应时的幂等键、活动 run 期间禁止再次提交，以及未完成的输入。
- **流式回答。** 显示排队、生成、正在停止、连接中断、完成／失败／已停止及半成品。读屏播报状态变化，避免逐字播报。断流后保留半成品，查询既有 run；显式停止须区分请求与终态。仅失败或已停止的运行显示重试。完成后采用服务端校验的持久化回答；切换会话清理旧请求与流。
- **引用。** 保留流中引用与持久化引用的归属、去重、分页及分别加载。仅 current 来源可跳转笔记／文件／事项；archived、deleted、missing 保留引用快照、位置与片段，显示具体状态。没有引用和读取失败各有反馈。
- **保存回答。** 仅已完成且可保存的助手消息提供操作。Dialog 内保留标题、根目录或具备完整路径的父页、取消、保存；读取目录失败时仍能存到根目录。提交中锁定重复动作，失败保留字段，相同请求重试复用幂等键，成功后刷新笔记列表并提供实际笔记链接。
