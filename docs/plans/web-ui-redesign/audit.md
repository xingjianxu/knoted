# 现有界面的浏览器核查

2026-11-19 在 Chromium 加载 dev HTTPS 的 `8b114cd` 页面产物，在浏览器中拦截 API，以固定合成数据提供只读响应。对 18 个路由模式及笔记历史、事项看板、文本预览、搜索命中共 22 个状态，分别在 1440×900 和 390×844 观察首屏；对笔记等重点场景补查 320 与 768px。下图为部分原始首屏的缩略拼图；坐标按未滚动视口的 CSS 像素计。认证仪式、实际搜索服务、Office 宿主通信和写入成功路径由后续业务卡验证。

**后续复测** 用同一类 fixture 从 URL 直接打开详情，滚动归顶后读取目标标题的 `getBoundingClientRect().top`，同时量取 Content 的 clientWidth 与 scrollWidth。至少覆盖短清单与 50 条清单：对象标题位置应与清单长度无关；窄屏可直接到达正文或主要操作。单测 DOM 中出现目标标题不足以证明它在首屏可见。
