# 12 · 跨页视觉与业务验收

**负责人及输入** 集成 Agent。在 01 建立样例时即准备对照数据；待 02–11 集成后验收最终版本。输入为各卡 PR、路由表、基线视口、交互录像或截图及当前锁版。修改范围限集成测试与验收记录；页面修正回到责任卡。

## 核对方法

1. 从浏览器地址栏分别打开总表的全部路径，记录页面名称、当前导航项、主操作、首屏实际可见内容。至少取 1440×900 与 390×844 两套样例；用 768px 检查侧栏临界态，320px 和 200% 缩放查找截断。截图用同一套合成数据、字体加载状态、浏览器、缩放与视口。
2. 以键盘依次进入主导航、内容、浮层并返回；检查当前项、可访问名称、焦点顺序、错误宣告与状态文字。控制台无新增未处理异常。全屏截图之外，留一组可见视口截图，才能对比进入详情时第一眼看到什么。
3. 按下表执行跨域路径。使用隔离的合成账号及测试实例完成需要写入的验收。逐项标明真实查询、fixture 或人工确认；测试输出与浏览器证据分别记录。

| 起点 → 终点 | 操作 | 通过条件 |
| --- | --- | --- |
| 登录 → 搜索 → 问答 | 带安全返回地址登录，搜索消息，打开命中，再后退 | 路由、选中消息、滚动位置与筛选条件符合已有行为 |
| 概览 → 事项 → 清单 | 打开到期项，查看跟进，再返回事项 | 首屏显示目标事项；到期日遵守上海边界，无列表来源时回默认清单 |
| 看板 → 事项 → 看板 | 在有筛选的后续页打开事项，返回后用键盘变更允许的状态 | 返回同一看板、筛选和游标；当前批次的列状态正确 |
| 笔记 → 历史 → 退出 | 产生草稿、模拟冲突及保存失败，尝试换页或退出；再安全恢复 | 草稿与处理入口仍可达；历史内容只读，完成退出后回登录 |
| 文件 → 预览 → 返回 | 从长列表打开文件；预览 PDF、图片、文本和 Office，关闭后返回列表 | 名称、来源和焦点可辨；关闭释放资源；Office 独立授权与宿主隔离正确 |
| 回收站 → 项目或笔记 | 对可恢复对象执行确认；再模拟成功后列表刷新失败 | 对象数据与相关列表一致；用户无需重复提交恢复 |
| 安全页 → 登录 | 取消删除凭据，之后撤销当前测试会话 | 取消回原控件；撤销后旧受保护视图不可继续使用 |

## 合并、证据和回退

- 分别运行 `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm build`、`pnpm exec playwright test tests/e2e/admin-layout.spec.ts`。按页面卡补充相关浏览器场景，记录 T71 实例验收前置与实际运行范围。按仓库规则保留 Rust fmt、test、clippy 与 diff 检查输出。
- 建立逐路由记录：地址、场景数据、视口、前后图、期望和实测、未验证项及原因。任何正文无法阅读、主操作不可达、离页丢草稿或越权预览的问题都回归对应卡后复验。
- 总负责人逐卡审核 PR → 普通 merge → 主线重跑受影响验证。需要回退时定位到责任卡提交，共享主题/依赖回退前核对已合入页面。独立记录本地与 dev 证据；生产部署不属于改版计划。
