## 页面与操作

| 场景 | 桌面结构 | 窄屏与键盘 |
| --- | --- | --- |
| `/projects` 名册 | 首行「项目」和主按钮「新建项目」。其下以 Segmented 区分未归档/已归档；List 按行显示可打开的项目标题及可选说明，已归档显示文字状态。列表尾放游标翻页。仅在当前筛选确实为空时显示对应 Empty。 | 名称与说明上下排列，长标题可换行，整行只留一个清晰的项目导航焦点。创建入口留在首屏。无项目时，空态与页首共用一个创建动作即可。 |
| 新建项目 | 主按钮打开 Dialog，名称在前、可选说明在后，下方取消/创建。提交中防重复，提交失败展示字段或表单错误，保留已填值。成功使列表失效并进入返回 ID 的深链。 | 弹层适合一列，软键盘打开仍可到达提交；取消回到触发器。 |
| `/projects/$projectId` 详情 | 由 01 的 Header 提供「返回项目」，内容从项目名、归档状态、编辑入口、更多菜单开始。正文先显示已有说明；下方按标签与资料分区。版本以次要元数据呈现，在编辑冲突时靠近操作。默认屏无需先滚过名册或创建表单。 | 单栏顺序为返回、标题/状态、操作、说明、关联。返回名册保留当前筛选和游标，直接输入深链无既有名册状态时回默认列表。 |
| 编辑与关联 | 「编辑项目」打开名称、说明和明确保存动作；编辑区只承载当前项目的草稿。标签先列已绑定项，添加时选择已有标签。资料先列类型和 ID，添加时再展开目标类型和 ID 输入。各分区独立保留翻页和错误。 | 关联目标长 ID 可完整查看并复制，行操作在键盘上可达。编辑冲突或请求失败时弹层继续显示输入与重试。归档项目直接阅读说明、标签、关联，写操作不可用。 |
| 生命周期 | 更多菜单提供归档或取消归档；已归档时将「取消归档」放到标题旁。归档失败在标题下列出阻塞事项及状态，并可用已有事项深链定位。删除独立放在菜单末尾，确认框说明条件、影响、清理资格。 | 先读到错误及解决办法，再到相应事项。删除确认失败在当前弹层显示，取消不发写请求，成功回列表。 |

## 状态与业务约束

- 列表区分首次加载、刷新、读取错误、活跃为空、归档为空。切归档筛选重置游标，加载期间禁翻页；沿用不透明游标，无总页数时只给前后页。深链可在项目不在当前列表页时直接打开；详情失败提供返回与重试。
- 新建名称去掉首尾空白且非空，名称上限 500，空说明按 null 提交。编辑只发送变更字段及 `expected_version`。409 显示可用的当前版本，保留两项输入并刷新服务端副本，用户核对后才能再次手动保存；不能用后台刷新覆盖草稿。
- 归档请求带版本。服务端 409 可能是版本变化或有未完成事项；要读完本项目 `todo` 和 `in_progress` 的各分页再列出实际阻塞项，查询失败呈现重试。成功归档及取消归档后刷新项目与事项查询。已归档项目只读，可取消归档后编辑。
- 删除要求项目下没有事项。删除将项目移入回收站，笔记和文件仍保留。删除满 30 天后具备清理资格；仍在回收站时由服务端复核恢复条件。删除失败保留当前项目与关联信息。切换 A→B 时，A 的标签、目标 ID、关联错误和编辑输入不能带入 B。
- 项目支持绑定已有标签及移除；目标类型与 ID 仍遵循原关联接口。标签选项、已绑定标签、关联各自使用自己的游标，读失败不发送写请求。目标已删除或文件失踪时继续显示原 ID。[关联行为](../../../apps/web/src/features/projects/ProjectAssociations.tsx) · [T38 回归用例](../../../apps/web/tests/tasks/t38.test.tsx)

3. 按阅读顺序改造关联分区与生命周期菜单，连接 409 阻塞清单、确认失败、取消和成功回跳。保留服务端错误信息和重试入口，验证「取消归档→编辑→再次归档」。
