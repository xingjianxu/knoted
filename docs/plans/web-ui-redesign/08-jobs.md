# 08 文件索引任务

目标是从当前批次中看出任务处于哪个阶段、是否需要干预，以及一次取消或重试是否已生效。入口为 `/files/jobs`，从文件页或直接链接访问。前置为 01-foundation 锁定的最新正式版 mtone（仓库基线 0.6.0）。沿用 AdminLayout 与文件导航选中态。队列和退出确认语义见 [ADR 0006](../../decisions/0006-file-pipeline-and-aggregate-contracts.md) 和 [ADR 0007](../../decisions/0007-execution-exit-confirmation.md)。

## 页面审计与排布

当前 JobsPage 在页首放扫描、刷新，下方单列任务状态，再按采集与解析、全文索引、向量索引、其他任务分组。尝试次数、时间和错误代码同列在标题下，行间难以对齐。当前页缺少向量任务就显示「未启用」，但列表请求仅含状态、游标和条数；筛选或翻页都可能让某个阶段恰好为空。

```text
文件 › 索引任务                          扫描文件
任务状态 [全部任务 ▾]                     刷新任务
采集与解析
任务名       状态       尝试       更新时间       可执行操作
失败行       失败       1/4        …              重试任务
             安全错误码及处理建议
全文索引  …      向量索引  …      其他任务（有记录时）
                                        上一页  下一页
```

用 Breadcrumb 或路由 Link 返回文件；扫描是整页主操作，筛选与刷新共用 FilterBar。每个阶段维持一个命名 section，内部用 List/ListItem 对齐业务字段，Status 标状态；逐条读屏时每个值都带上下文。窄屏将「状态、尝试、时间」排在名称下，次行显示错误与当前可用操作。失败与运行任务共享同一阅读顺序。桌面与手机均在整个批次末尾翻页。

## 状态与操作

| 服务端状态 | 行上的文案与动作 |
| --- | --- |
| queued／running／retry_wait | 排队中／运行中／等待重试；可发起取消。ConfirmDialog 提醒可能须等待执行退出。 |
| cancel_requested | 正在取消，等待服务端确认后再显示终态。 |
| failed／cancelled | 失败／已取消可在确认后重试。新执行与原记录并存，原错误说明可继续查阅。 |
| succeeded | 显示「已完成」及时间，行不出现重试或取消。 |
| 首次读取、空页、读取失败 | Spinner、单个 Empty 或带刷新入口的 Alert；分组空态仅陈述本页结果。有明确未启用错误码时显示相应功能状态。 |

页面保留安全错误映射 `jobProblem`、未知类型与错误的兜底。行内操作失败在确认上下文中可见，扫盘失败在工具栏下重试。带活动记录的当前页沿用 2 秒查询，完成后停止；忙碌与轮询时翻页禁用。用户提交扫描后网络结果不确定时显式重试复用同一幂等键，成功后新的用户意图使用新键。
