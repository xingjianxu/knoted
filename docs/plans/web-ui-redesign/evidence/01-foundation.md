- 用键盘跳过导航后进入唯一的主滚动区，项目/事项详情可返回对应清单，父导航保持当前态。退出和笔记保护沿用原链路，原 T31 的 409/503 保存失败退出用例验证草稿保留且不发送退出请求。
- Chromium 用已缓存长回收站验证后退复位、前进归顶，并延迟概览响应，验证概览在取数后恢复历史位置。恢复只在内容初次太短时补做，会让位给用户主动交互、URL 锚点和问答消息定位。搜索命中已缓存问答消息后目标被聚焦并进入视口。
- 模拟会话请求 503：错误页显示标题与 Alert；从重试按钮按 Enter，等待状态可见并禁用重复触发；再次 503 后恢复重试焦点，下次成功进入概览。未知地址的「返回首页」是可直接打开的链接。

## 下游使用

`AdminLayout.Content` 仍是唯一外壳滚动容器。`.workspace-frame` 提供约 1120px 版心；笔记、问答及承载看板的事项路由允许满宽。另外可直接用 `.reading-measure`（68ch）、`.page-title`、`.section-title`、`.page-link`；每个业务模块继续拥有自己的标题与交互。游标导航样例仍使用 mtone Button 与应用游标状态，见 [T19](../../knoted-v1/evidence/t19.md)；不造总条数，取数中锁定翻页，业务列表改造不在本卡完成。

`npm view @bixlab/mtone dist-tags.latest` → `0.6.0`。发行包 `package.json` 公开根类型、`styles.css`，React/React DOM peers 为 `^19.2.0`；应用仍为 `19.3.1`。实查 `dist/index.d.ts` 和同版 `llms.txt` 的 `AdminLayout` slots、Sider 折叠与 Button loading，复用现有 UiProvider tokens；无需修改锁定版本或申请上游能力。
