## 接口与裁定

- `document` 是初始值；调用者按笔记 ID 为组件设置 key。组件不因保存回调或查询更新重建 editor，避免覆盖未保存修改或打断输入法。
- `children` 位于 BlockNote 上下文内，供后续菜单等业务组合消费，不在本卡提前实现。
- 默认 image 使用 URL 且没有格式化图注，默认 codeBlock 为 plain；本卡用公开自定义块保留 image assetId/inline 和 code language/inline，图片读取和菜单由后续卡完成。
- 默认行内 code mark 排斥其他 marks，与后端允许五类 marks 组合不一致；通过其公开 `mark.extend({ excludes: "" })` 保留解析和快捷键能力。
- `fromEditorBlocks(blocks, source?)` 的 source 保留未改动 inline 分段；level/checked/language/assetId 通过共享编辑器 props 和原生历史保留最新值及跨类型字段，避免初始 DTO 恢复旧语义值。NoteEditor 自动传入 source。编辑后的文字使用确定的 mark 顺序和分段。
- BlockNote 0.57 的 `attributionTooltip` prop 被错误转发到 DOM；使用公开 `disableExtensions: ["attribution"]`，其他默认 UI 都显式 false。
- 浏览器服务使用本卡临时 Vite 配置（仅 React/Tailwind），避开已知 Issue #73 的旧 fixture 路由扫描问题；不顺手修复该问题。
- 合成 composition 和 Chromium CDP 组合事务不能代表操作系统 IME 验收；仍需人工真实中文输入法复验。

实际命令、结果与限制见 [T27 证据](knoted-v1/evidence/t27.md)；完整原始输出保存在 `/data/knoted-dev/tasks/t27/`。
