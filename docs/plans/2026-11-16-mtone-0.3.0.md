# mtone 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按用户直接委派将 `@bixlab/mtone` 从 0.2.0 精确升级至已发布的 0.3.0，同步必要消费代码、测试及现行文档。

**Architecture:** 继续直接消费 npm 公开 Provider、组件和预编译 CSS，不新增包装库，不改 API/存储契约。由主 Agent 串行升级、独立 Reviewer 只读审查，正常 PR 普通合并后验证主线并清理。

**Tech Stack:** pnpm 12.9.0、React 19.3.1、TypeScript、Vitest、Playwright Chromium、Rust workspace。

**Spec:** 用户本次请求「将 @bixlab/mtone 包更新到 0.3.0 版本。并更新相关代码和文档」；[ADR 0002](../decisions/0002-mtone-ui-ownership.md)、[UI 指南](../development/ui-mtone.md)。

## Global Constraints

- Worktree `/wrd/prj/knoted/.worktrees/mtone-0.3.0`，分支 `chore/mtone-0.3.0`，基线 `a2e0e36`；不操作其他任务 Worktree。
- 使用正式 npm 0.3.0；检查用 tarball 不是安装来源；不改 mtone/Base UI，不 patch，不引入 link/file/Git 依赖。
- 仅必要兼容适配，不采用本次升级不需要的新组件；保留 T17—T20、旧计划与 Accepted ADR 中的真实 0.2.0 历史。
- 现行文档明确当前版本；新增发布包 `llms.txt` 参考入口，类型声明与消费测试仍是完整接口/兼容性依据。
- 远程常规操作按根 AGENTS.md 默认授权；生产部署、主机配置不在本任务范围。

## Review Focus

- Form 新增托管表单能力不得改变现有手动受控表单提交、字段关联与禁用语义：复跑 t17 与认证 Vitest。
- Dialog/Modal 别名及弹层实现变化不得破坏键盘、焦点返回、Portal tokens/字体：复跑 t18 Chromium。
- Tree 的展开/选择分离、disabled 语义及无 total 游标往返保持：复跑 t19 Vitest/Chromium。
- 新依赖和 CSS 不得引入远程字体，构建保持公开导入：复跑 t02、t17 Chromium、build。
- package/lock/实际安装版本一致；冻结安装可复现；只更新明确选择版本的 release-age 例外，不放宽全局策略。
