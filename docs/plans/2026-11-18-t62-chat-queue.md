## 实施记录

- 会话以账号作为所有者，创建默认选择 local。外部服务须在配置中显式存在。问题、回答占位、run、任务、幂等结果和 queued 事件同事务建立。失效幂等键不参与去重。重试创建新 run，并保留原问题和回答 ID。
- 单一生成槽以部分唯一索引保证。等待中的任务保留在既有队列，当前 run 确认终止后才放行下一任务。取消与租约接管复用 T08。模型请求发出前保存意图；无终止证明时保留槽；恢复进程不重发旧 run。对话提交失败与队列终态之间的不一致由 Worker 检查和恢复。
- 生成事件在数据库有连续 seq。SSE 可从 Last-Event-ID 恢复，断连客户端也可独立读取 run 状态。最终回答保存、完成事件和全文 outbox 同事务提交。公开失败状态保留 partial，并用 `generation_interrupted` 表达内部中断。
- 只为完整聊天文字发布 document 全文。软删除后，新检索请求由 PG 即时过滤旧词条。聊天检索命中包含 `session_id` 供 T65 跳转，业务分块和向量没有聊天来源。
- T63 将接续来源依赖和上下文预算，T64 接续引用快照与证据校验。
