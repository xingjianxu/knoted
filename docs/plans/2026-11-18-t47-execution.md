# T47 执行退出证明实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development；恢复原 T47 实施者，按下面顺序实施，不重复阶段 A。

**Goal:** 把已确认的计算退出证明接入真实 PDF/图片 file.extract 管线、固定产物及 dev，完成 T47 后再接续 T48—T50。

**Architecture:** 延用 jobs/lease、SQLite execution 账本、staging、成功提取表和内部 HTTP。guardian 在 intelligence 包内部监督单次计算；Rust 持久登记尝试后才 POST，确认旧计算回收后才允许后继。无法证明时保留占用并 degraded。

**Tech Stack:** Rust 2024/PostgreSQL、Python 3.12.15、锁定 Docling/RapidOCR、Linux pidfd/subreaper、pcwrap。

**Spec:** [ADR0007](../decisions/0007-execution-exit-confirmation.md)、[获批 RFC](../rfcs/2026-11-18-t47-execution-exit-confirmation.md)、[T47](knoted-v1/tasks/T47.md)、[总计划](2026-11-17-t39-t50.md)。2026-11-18 用户针对该补充 RFC 回复原文“通过，基于执行”；不再等待同一批准。

## Global Constraints

- 所有文件修改在主根 `.worktrees/` 内；一个产品写 Agent，主 Agent 负责契约、集成、独立验证和 dev。
- 不改 ADR0006 历史正文；不新增第二套业务队列、状态枚举、宿主权限/cgroup、生产部署或依赖升级。
- 源只读；只从闭合 staging 计算；100MiB、PDF500页、图片40,000,000像素、执行900秒；未完整成功不发布。
- dev 显式 CPU，CUDA_VISIBLE_DEVICES 与 KNOTED_EMBED_GPU_UUID 为空，Docling device=cpu；两个共享模型根只读，不联网下载、不碰 Strata。
- 父/guardian/compute 运行同一完整 SHA 的解释器/锁定依赖/源码，`-I -B`，cache/tmp/state/staging 外置。
- 旧 helper 的 cancelled-only 含义不变；resource proof 与 request echo/terminal/显式退出证明共同验证，不能凭 404、超时、interrupted 或 leader PID 消失放行。

## Review Focus

- leader 先退而后代存活、TERM 忽略、API SIGKILL：唯一监督者须回收到 ECHILD 并持久证明，不能只 wait leader。
- 启动 intent/READY/GO/结果写入的崩溃窗口：无完整证明保留占用；不误杀无关 sentinel。
- 丢 POST 响应/迟到 POST/接管：同 ID 原完整请求/原 deadline；404 不是证明，过期首次 materialize 也封闭未来启动。
- 旧 lease/来源变化/取消409与自然终态：退出证据不能代替当前来源和发布 fence。
- 固定产物、SQLite/凭证备份和 process-compose 停止：不能用 API/Worker PID 消失代替计算回收，不激活 worktree/可编辑运行源。
