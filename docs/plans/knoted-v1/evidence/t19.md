## 限制与主 Agent 承接

- ConfirmDialog pending 只保证确认/取消按钮禁用；**Esc 仍可关闭**。本卡没有生产确认业务，不承诺请求取消或不可关闭，沿用 T18 已验证边界。
- Tree 公开 `value/onValueChange`、`expanded/onExpandedChange` 传递的是 id 而非 label；夹具输出 id 作为探针，业务显示映射留给后续消费页，本卡不引入通用映射库。
- Pagination 依赖 total，与 items/next_cursor 游标契约不匹配；本卡用 Button 组合上下页，不伪造 total、不改后端协议。
- 完成范围是本地实现与验证、提交交接；作者自审不代替独立 reviewer。主 Agent 承接独立差异/门禁复验、review、PR 普通 merge、主线再验证、Issue/Projects 与本任务 Worktree/分支安全清理。
- 无新增架构或不可逆变更；未改 Accepted ADR 正文。T20 未执行。
- 下游消费约定（来自独立审查分诊）：同一游标重复派发 `next` 会重复压栈，后续列表页应在加载期间禁用翻页按钮；夹具对未知游标的回落仅限测试 stub，不复用到生产。
