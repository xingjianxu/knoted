## 实现与公开能力

输出 `editor/menus/` 的 `SlashMenu`、`BlockMenu`，在 T27 NoteEditor 的 children 内组合；不修改 NoteEditor.onChange 和 schema/DTO。关闭默认 UI 后，公开 GenericPopover 根据 SuggestionMenu 的 referencePos 定位，官方 useSuggestionMenuKeyboardNavigation 处理方向键/Enter，mtone Card/List/ListItem/Button 提供选项。块操作直接消费 SideMenuController 与受控 DropdownMenu；按 Escape 后回到编辑器并保留 ProseMirror 选区。

发布包源码 `@blocknote/react/src/components/SuggestionMenu/SuggestionMenuWrapper.tsx` 先清查询再执行命令；`SuggestionMenuPopover` 没有从根导出。`clearQuery()` 内部 Tiptap chain 独立 dispatch，实验放在 editor.transact 中触发 active-transaction 异常，已放弃。最终在公开 editor.transact 的 tr 中核对并删除 `/` 加 query 后执行命令，形成一次 onChange；未使用私有导入、事务拦截、onChange 合并、Base UI 或本地通用菜单。官方说明：[Suggestion menus](https://www.blocknotejs.org/docs/react/components/suggestion-menus)、[Side menu](https://www.blocknotejs.org/docs/react/components/side-menu)，以安装的精确发布包为实现依据。

原生移动会进入相邻块已有的 children，位于兄弟边界时移出父块。菜单预测目标父层级加完整移动子树深度；8→9 层移动禁用且执行入口再次检查，合法 8 层移动正常。5000 块时新增块禁用且键盘入口拒绝，保留斜杠/query；空块转换不增加块数仍正常。图片动作留给 T29 的真实资产上传，本卡不插入临时图片。分类为已有公开组件可组合，无 mtone 通用缺口。
