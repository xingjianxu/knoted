基线 `4ef04e3`，已核对包含 T15 `32cbb6f` 与 T22 `8d4a472`。主Agent为唯一应用实施者，隔离路径 `.worktrees/knoted-t23` / `feat/t23`。

- `notes::service::{create,get,list,update,delete}` 使用 `&AppContext` 与命名输入，产出 T03 Note/NotePage；API仅适配JSON、分页、ETag、错误信封。
- 新增迁移 `0005_t23_notes.sql` 建 notes 表，FK注册实体/父笔记、版本与位置约束及live列表索引；未修改旧迁移。
- service持有事务。内容更新锁行并用ID/version/deleted SQL CAS；创建/删除先拿按notes表OID隔离的事务锁，同级追加/重排、父校验与子创建/父删除互斥。错误返回前显式await rollback。
- title/document语义相同时不增加content_version/outbox；生命周期软删除增加版本并隐藏普通详情/列表，活子节点阻止父删除。同级position紧凑重排属于排序元数据，不改其他笔记语义内容版本。
- 当前没有索引handler，`note.changed`事件只保留未发布outbox（job_id为空），payload仅source_id/content_version/operation；不拷贝正文、不让Worker消费未知job kind。
- list默认50、范围1—100；按(position,id)键集，游标含版本、排序键、UUID及完整parent过滤条件；省略parent_id按T03表示不过滤。
- RawValue保留传入document原始字节，复用T22严格校验后才转JSONB，重复键不被通用Value解析吞掉。启用已有serde_json raw_value，无版本更新；T03补充既定2MiB限制的413响应并重新生成客户端。
- CRUD复用既有session/Origin/CSRF。DELETE按T03用expected_version query；其余更新body。详情/创建/更新返回ETag `"<content_version>"`。
- 不实现树移动/恢复、快照、图片引用记账或索引消费；分别留给既有后续卡。
