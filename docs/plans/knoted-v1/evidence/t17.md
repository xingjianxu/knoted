## 实现边界

- `apps/web/src/lib/ui-provider.tsx` 仅配置公开 Provider 的中文 locale、compact density 与应用主题 tokens。不是组件转发层。
- CSS 顺序 `theme, base, mtone, components, utilities`；预编译 CSS 放在 `mtone` 层，系统字体适配覆盖 `.mt-scope` 及发布 CSS 中独立声明字体的公开范围。主题 tokens 经 context 同样传到 body-level MtoneScope。
- `main.tsx` 使用该 Provider；App 只迁移原静态类，不增加生产表单演示。
- 移除 `packages/ui/` 的 workspace manifest 与源码，清理依赖/lock/ESLint 的实际引用；旧安装留下的 ignored `node_modules/` 不属于源码包，不要求删除。T02 字体扫描改查发布 CSS。T02/T04 历史交付证据不改写。
- 表单组合在 `apps/web/tests/fixtures/`；Playwright 通过测试专用 Vite config 启动/停止服务，端口 4177、`strictPort`、不复用未知进程。HTML 在 `tests/e2e/fixtures/`，不进入生产入口。配置采用 `.mts`，避免仓库根 CommonJS 作用域错误加载 ESM 插件。
- body-level scope 是真实 React portal 中的公开 `MtoneScope` 字体/主题探针；**不代表已验证 T18 弹层、焦点陷阱与关闭生命周期**。未接入 RHF，不声称覆盖业务表单校验。
