## 限制、裁决与主 Agent 承接

- disabled 菜单项可聚焦是实测契约，不是功能缺口；禁用必须阻止执行。Modal inert guard 的瞬时焦点是上游回绕机制，不将其误报为逃逸，也不自行补焦点实现。
- ConfirmDialog pending 只保证确认/取消按钮禁用；**Esc 仍可关闭**。本卡没有生产确认业务，不宣称保证事务取消/不可关闭。后续业务必须明确请求生命周期，若需不可关闭，先验证受控公开 API 组合；本卡不擅自增加统一保护 wrapper 或承诺不存在的上游行为。
- Toast 默认自动关闭配置未改；夹具给单条 Toast timeout0 只为稳定观察显式关闭，不代表产品统一永久通知策略。
- 完成范围是本地实现与验证、提交交接；作者自审不代替独立 reviewer。直接委派禁止实施 Agent 派生任何子 Agent、远程写/push/PR/merge。主 Agent 承接独立差异/门禁复验、review、PR 普通 merge、主线再验证、Issue/Projects 与本任务 Worktree/分支安全清理。
- 无新增架构或不可逆变更；未改 Accepted ADR 正文。T21 前没有持续测试实例；本轮 smoke 仅本地验证，不是部署。T19 未执行。
