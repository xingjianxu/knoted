```rust
validate_document(&AppContext, ValidateDocument) -> Result<ValidatedDocument, DomainError>
extract_plain_text(&AppContext, ExtractPlainText) -> Result<PlainTextDocument, DomainError>
```

`ValidateDocument { format_version: u32, document_json: String }` 按原始UTF-8字节检查2MiB；版本仅1。全部层级合计5000块、最多8层（顶层1），块ID唯一且1—64字符。严格serde拒绝未知字段/枚举、重复键、类型错误及显式null；heading必须level1—3，image必须标准连字符UUID asset_id。链接只允许绝对http/https/mailto，scheme大小写无关，原始URI须ASCII且编码合法；不接受任意协议或HTML节点。

验证成功才能构造 `ValidatedDocument`；只读 `document_json()` 保留原始JSON、不静默丢字段，Debug不展示正文。提取输入 `ExtractPlainText { document }`，返回整体text及每块 `block_id/path/text`，按前序遍历（含空块/图片）用单个换行分隔，不trim中文/代码/空格/换行。图片不展开受鉴权URL。

`DomainError::{UnsupportedVersion, LimitExceeded, InvalidDocument}` 的状态映射422/413/422，不引入HTTP框架依赖。结构错误只定位`$`，避免serde诊断包含正文；语义错误保留固定字段/索引路径。AppContext仅保留调用约定，无数据库I/O。
