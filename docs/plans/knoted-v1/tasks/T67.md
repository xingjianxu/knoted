## 实施细化

基线为 `f796437`。复用 T26 的私有资产根和引用写锁、T37 的独立 Worker 维护循环，以及 ADR 0007 的持久计算退出证明。主 Agent 实现和集成，独立审查聚焦授权目录、并发以及部分失败重试。

- 资产删除先在引用锁内把已登记、零引用满 24 小时的记录转入 deleted。事务提交后按资产 UUID 删除对应对象，成功后记录完成。中断后保留待删除标记，续跑处理。保留缺少登记的未知文件，无法从当前数据库证明其归属。同键重放仍返回原资产 ID 和当前状态，编辑器拒绝插入已经回收的图片，提示重新选择文件。
- 暂存回收只查看本实例 input/output 目录中的受控 ID。执行到达持久终态满 24 小时且已有退出证明，再按已知 ID 回收产物、子进程状态和嵌入输入。原始采集对象留给文件采集链维护，执行证明和业务记录保留。
- 目录操作使用描述符，拒绝符号链接和跨越挂载点；利用已打开描述符的 mount ID 与实际挂载根核对源和可写区的别名。路径或对象类型异常时保留原对象。
- 验收真实 PostgreSQL 历史引用、零引用时限及引用锁竞争，受控 HTTP 终态、超时、路径隔离，再在合入主线后验证 Worker 周期回收和 dev 数据保护。
