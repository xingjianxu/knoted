# mtone 0.6.0 与工作区布局设计

## 目标与范围

将 Web 精确升级到正式发布的 `@bixlab/mtone@0.6.0`，在所有已登录路由共享的 `_authenticated` 外壳直接使用公开的 `AdminLayout`。用户在会话确认：现有导航继续可用，窄屏自动收成图标栏，退出登录留在上方；登录和初始化页不展示工作区导航。

不改变 URL、页面权限、Passkey、会话退出流程、笔记自动保存及阻止离页的语义，也不改业务页面设计、后端、存储或部署。继续遵守 [ADR 0002](../decisions/0002-mtone-ui-ownership.md)，不增加 UI 转发层或使用库的私有接口。

## 方案

选择只在已登录路由替换外壳：左侧为品牌、现有分组及导航（窄栏图标仍有可访问名称）；右侧顶栏提供退出登录，下方是独立滚动内容。使用 mtone 原生折叠、断点及 slots；应用继续负责路由和离页保护。使用已在锁文件存在的 Lucide 同版本图标，在 Web 公开声明直接依赖，不从 mtone 的传递路径导入。导航后的内容容器应像先前的文档滚动一样回到顶部；同一页面的业务交互不合并进外壳。

比较：只升级依赖保留旧布局，无法交付工作区统一；在根路由同时包住登录和初始化，改动范围更大且无收益，未采用。正常桌面宽度使用展开栏；低于 768px 由 `AdminLayout.Sider.breakpoint` 收起，不增加抽屉、偏好持久化、面包屑或页脚文案。
