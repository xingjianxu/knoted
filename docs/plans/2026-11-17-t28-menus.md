## 公开接口取舍

`SuggestionMenuController` 默认 wrapper 先调用 `clearQuery()` 再执行选项命令，不能原子提交两者。发布包的 `SuggestionMenuPopover` 未从根导出；禁止私有导入。采用公开 `GenericPopover`、`SuggestionMenu` 状态与注册 API、`useSuggestionMenuKeyboardNavigation`。菜单在公开 `editor.transact(tr => …)` 中核对光标前文本确为 `/` 加当前 query，再删除该文本并执行块命令；不拦截事件或合并 onChange。清查询和命令共享一个事务，保留原生历史。

mtone 的 Card/List/ListItem/Button 提供菜单表面与选项；受控 DropdownMenu 提供块操作菜单，公开 SideMenuController 负责物理触发器定位。菜单内容和 BlockNote 命令是 Knoted 的业务组合，无通用组件缺口，无上游 Issue 或依赖改动。通用 CSS 与基础控件实现均来自正式 npm 包。

块移动遵循 BlockNote 的公开语义：相邻块已有 children 时进入其 children，位于兄弟边界时移出父块。保护逻辑预测实际目标父层级加整个移动子树的深度；超过 8 层时禁用并拒绝执行。斜杠插入在 5000 块时仍允许转换空块，需要新增块时拒绝且保留查询。
