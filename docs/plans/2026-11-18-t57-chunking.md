## 实施记录

- 采用锁定 BGE-M3 快照的 `tokenizer.json`，以 SHA-256 和文件大小校验。Rust tokenizer 依赖禁用网络下载和默认特性。Worker 从既有环境变量 `KNOTED_INTELLIGENCE_BGE_M3_DIR` 读取同一快照。
- 独立集合以文件提取 ID、笔记版本或事项及跟进修订为输入生成。PDF 页、XLSX 表、Office 结构定位、笔记块 ID、事项跟进 ID 和源块内 UTF-8 范围保存在分块位置。不同页、工作表、标题和独立跟进记录保留结构边界。同一表格行尽量保存在同一块，长行仍受最大 token 限制。
- 已入队文件可处理同一内容版本的成功提取。扫描重新确认摘要前，`current_rag_sources` 隐藏对应分块。版本或提取身份变化后，旧集合不可成为当前候选。
- 扫描任务和词法发布共享 Worker 队列。分块实时发现与旧数据补建使用有界、幂等的单独调度。发布按 64 条一批提交，任务 ID 和进度受租约保护，最后一批成功后才发布集合。
- 所有候选按当前来源、提取身份和分块修订复核。分块词法索引 UID 由 `[search].rag_chunk_index_uid` 独立配置，默认 `knoted_rag_chunks`。向量和混合候选分别由后续卡消费。
