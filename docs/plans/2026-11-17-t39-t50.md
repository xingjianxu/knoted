# T39—T50 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. 按卡执行，不提前标记完成。

**Goal:** 完成事项页面、看板、概览与回收站，以及只读文件扫描、稳定采集、解析、浏览和预览。

**Architecture:** 延用 Rust core 事务服务、axum HTTP、Worker jobs、Python staging 执行协议与 React/mtone。每卡独立实施、审查、PR、部署、主线验证；共享契约和迁移由主 Agent 串行协调。

**Tech Stack:** Rust 2024 / PostgreSQL / React / @bixlab/mtone 0.4.0 / Python 3.12 / 锁版 Docling、RapidOCR。

**Spec:** [现有任务卡](knoted-v1/README.md)、[需求](knoted-v1/requirements.md)、[数据/API](knoted-v1/data-and-api.md)、[索引/RAG](knoted-v1/indexing-and-rag.md)。用户本次直接授权 T39—T50，并指定使用 subagent。

## Global Constraints

- 所有文件修改（含文档、配置）在独立任务分支和 Git Worktree 中完成。
- 唯一允许的位置是主仓库根目录的 `.worktrees/<task>`，不得嵌套。
- 一张卡一个实施 Agent；每卡后独立审查，主 Agent 验证集成。写任务串行；只读研究可并行。
- 通用 UI 使用 npm `@bixlab/mtone`，不在 Knoted 实现通用组件库或转发层。
- 只读源目录；不执行宏、公式、外链或代码；不修改宿主共享服务。
- 输入采集上限100MiB，PDF500页，图片40M像素，执行900秒；预览50MiB。
- 重大架构决策、跨模块接口与存储契约补充先提供具体方案并取得人工确认。
- README 状态列使用 `done（PR #N，主线 SHA，dev SHA；证据）`，所有值来自实际读回。
- 不直推 master；默认授权普通 merge PR、测试实例更新，不授权生产或破坏性操作。

## Review Focus

- 切换实体与迟到响应：表单、关联、预览不得串数据（T39/T42/T50）。
- CAS 与终态门槛失败：保留草稿，状态回滚，重试采用刷新版本（T39/T40）。
- 根失联、权限变化、扫描中断：不得据此批量标记来源失踪（T43）。
- 文件读取与版本竞态：拒绝 symlink/FIFO，变更丢弃，不发布旧版本（T44/T45/T47）。
- 非法编码、损坏文档与取消：明确终态、不发布截断结果，确认进程退出（T46—T48）。
